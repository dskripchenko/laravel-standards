# PHP

`STACK-01` и `PHP-01`–`PHP-06`. Новый код целится в PHP 8.5. Существующее
приложение на 8.4 или 8.3 остаётся на своей версии до обновления, и новый
код в нём использует только то, что эта версия умеет. PHP 8.2 целью новой
работы не является. PHP ниже 8.2 вне этого стандарта (`CORE-06`).

Laravel 13 — фреймворк нового приложения. Пакет объявляет те версии
Laravel, на которых реально гоняются его тесты.

## Инструменты

Проект сохраняет свой форматер (`PHP-02`). Pint — для нового проекта и для
проекта, который его уже запускает, — использует пресет Laravel и
обязательный strict types:

```json
{
    "preset": "laravel",
    "rules": {
        "declare_strict_types": true
    }
}
```

Larastan на `level: max` для нового приложения. Существующее приложение
держит свой уровень и не снижает его. В пути анализа входят `app/` и
`tests/`.

Каждый файл начинается так:

```php
<?php

declare(strict_types=1);
```

## Типы и ветвления

Сравнение строгое. `match` — когда каждая ветка даёт значение. `??` — для
отсутствия. Именованные аргументы — когда два параметра одного типа.

```php
$label = match ($status) {
    OrderStatus::Pending => 'Pending',
    OrderStatus::Paid => 'Paid',
};
```

```php
enum OrderStatus: string
{
    case Pending = 'pending';
    case InProgress = 'in_progress';
    case Paid = 'paid';
}
```

Константы типизированы и названы `UPPER_SNAKE_CASE`. Варианты enum —
PascalCase. Замкнутый набор не кодируют константами класса.

Продвижение свойств конструктора — для зависимостей и неизменяемых данных.
Исключение — контроллеры handbook: их зависимости приходят через метод
(`shapes/handbook.md`). Функция с логическим флагом, который переключает её
между двумя делами, — это две функции. Цепочка `instanceof`, которая
выбирает поведение, означает, что у этих типов не хватает общего метода.

Глобальную функцию не пишут. Паттерн «одиночка» запрещён (`PRIN-05`): нет
`getInstance()` и нет изменяемого статического состояния. Привязка
`singleton()` в контейнере разрешена. В тестах привязку подменяют.

Новая строка укладывается в 120 символов (`PRIN-06`). Файл, который уже
живёт с более длинным пределом, сохраняет его, пока отдельной задачей не
сменят форматер.

## Состояние

Поля, которые вызывающий не должен менять, — `private`. У модели задан
`$guarded` или `$fillable`, и никогда `$guarded = []`. Публичное изменяемое
свойство у сервиса — дефект.

Предпочитают композицию. Наследование — только от класса фреймворка или от
базового класса проекта, которого требует каркас.

## Комментарии и мёртвый код

PHPDoc на английском и нужен там, где сигнатура не выражает тип: `@property`
у модели, форма массива, `@input` и `@output` у метода API. Строчный
комментарий объясняет ограничение. Закомментированный код удаляют, а не
хранят.

## Чего Pint не решит

Pint не выберет имя. Имена — английские слова про суть: `$project`, не
`$p`; `archive()`, не `handle()`. Коллекция — во множественном числе, одна
запись — в единственном. Имя класса в свойстве не повторяют
(`Project::$name`, не `$projectName`).
