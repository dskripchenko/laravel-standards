# Эксплуатация

Очереди, исходящие вызовы, флаги, журналы и кеш. Коды правил — `JOB-*`,
`INT-*`, `FLAG-*`, `OBS-*` и `CACHE-*`.

## Очереди

Задачу, которая отправляет письмо, зовёт внешнюю систему или пишет строку,
пишут так, чтобы второй запуск не удвоил эффект. Обычные формы — уникальный
ключ строки или проверка, что работа уже сделана.

```php
public int $timeout = 30;

public function retryUntil(): DateTimeInterface
{
    return now()->addMinutes(10);
}
```

`$timeout` меньше `retry_after` очереди. Задачу, которая работает дольше
`retry_after`, второй работник возьмёт, пока первый ещё внутри.

Конструктор принимает идентификаторы и скаляры. Метод `handle` загружает
модели. Сериализованная модель Eloquent — устаревшая копия, и она ломается,
когда класс переезжает (`JOB-02`).

```php
$schedule->command('reports:daily')
    ->dailyAt('06:00')
    ->withoutOverlapping()
    ->onOneServer();
```

## Долгий HTTP-вызов

Предпочитают задачу очереди (`JOB-01`), если проект ещё не использует
`dskripchenko/laravel-delayed-process`. Если использует, контроллер
возвращает UUID, который выдаёт пакет, класс стоит в списке разрешённых, а
существующий перехватчик на фронтенде опрашивает статус. Подробности — в
файле каркаса.

Долгий деловой процесс с таймерами, ожиданием и действиями оператора идёт
через `dskripchenko/laravel-process-engine`, если проект его уже имеет или
если задача — в том, чтобы его ввести (зависимость — через `CORE-08`).
Экраны админки для этого движка описаны в `shapes/laravel-admin.md`.
Приложение forge, которое движок уже запускает, следует `shapes/forge.md`.

## Исходящие вызовы

Клиент создают с таймаутом. Повтор оборачивает только вызов, который
безопасно отправить дважды (HTTP GET, который сам не размещает заказ,
опрос). POST, который списывает деньги или создаёт сущность, вслепую не
повторяют. Журнал вызова хранит имя операции, статус внешней системы и
идентификатор запроса (`OBS-01`). Тело с персональными данными или секретом
он не хранит (`SEC-03`, `SEC-07`).

Тесты подменяют внешнюю систему. Фикстуру, снятую с настоящего ответа,
используют только после того, как идентификаторы, имена и номера документов
заменены синтетическими значениями (`INT-02`).

Хост берётся из конфигурации. Хост, который пришёл от пользователя,
сверяют со списком разрешённых до того, как его увидит клиент (`INT-03`,
`SEC-06`).

## Флаги

```php
final class Experiments
{
    public function checkoutVariant(): string
    {
        return (string) config('experiments.checkout');
    }
}
```

Вызывающие зависят от `Experiments` или от класса, который в проекте уже
есть. Тест принуждает вариант заголовком проекта только когда отладочный
токен совпал (`FLAG-02`). В конфигурации production токена нет. Тест
поднимает приложение с пустым токеном и проверяет, что заголовок ничего не
меняет.

## Журналы и кеш

`OBS-02`. Одной структурной строки на сбой достаточно, если в ней есть
идентификатор запроса и идентификатор в домене.

`CACHE-01`. Ключ и TTL называют рядом, в конфигурации. Сброс идёт тем
способом, который проект уже использует. Новый трейт, чья единственная
работа — чистить ещё один кеш, и есть тот второй способ, который правило
запрещает.
