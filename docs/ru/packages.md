# Пакеты, которые мы публикуем

`PKG-01`. Свой пакет — библиотека, которую требуют другие репозитории. Это
не приложение и не этот пакет стандартов. Пакет стандартов остаётся только
документами (`STD-03`).

## Среда выполнения

`composer.json` объявляет то ограничение PHP, на котором реально идут тесты.
Порог для нового пакета — `^8.2`. Пакет, который должен обслуживать старые
приложения, перечисляет версии Laravel, которые гоняет его CI, и не обещает
более широкий диапазон.

Пакет не требует SQLite. Тесты, которым нужна база, идут на тех движках,
которые пакет заявляет (`DB-01` для приложения; для пакета — движки,
названные в README).

## Тесты и анализ

PHPUnit или Pest — один из них, тот, который пакет уже использует. Новый
пакет использует Pest. Larastan идёт в CI. Файл baseline допустим и только
уменьшается: изменение, которое добавляет проигнорированную ошибку, не
принимают.

## Автоматизация и безопасность

GitHub Actions на запросе слияния гоняет тесты, Larastan и `composer audit`.

`SECURITY.md` говорит, куда сообщить об уязвимости. В нём нет ключа, имени
заказчика и внутреннего хоста.

README публичного пакета — на английском (`LANG-01`). Переводы, если пакет
их ведёт, лежат рядом (`docs/ru` и другие языки, которые у пакета уже есть).
Журнал изменений — Keep a Changelog. Версии правил пакета следуют `STD-01`,
версии кода — обычной семантике.

## Чего в репозитории нет

Закоммиченного `composer.phar` (`DEP-08`). Отладочного пакета в `require`
(`DEP-07`). Адреса частного кеша в lock-файле (`DEP-06`). Копии этих
стандартов. `AGENTS.md` пакета импортирует этот пакет
(`templates/claude-import.md`) и добавляет паспорт.
