# Документация

## Какой язык

`LANG-01`.

| Текст | Язык |
| --- | --- |
| Требования, ADR, архитектура и README внутреннего проекта | Русский |
| Публичные README и `docs/` | Английский. Переводы рядом. Внутренние заметки остаются русскими. |
| Код, PHPDoc, JSDoc, комментарии, имена тестов | Английский |
| Описания OpenAPI | Английский |
| Идентификаторы на схемах | Английский; подписи могут быть русскими |
| Правила этого пакета (`AGENTS.md`, `docs/`) | Английский |
| Перевод этого пакета (`docs/ru/`) | Русский |

Русские документы пишут обычными словами и с буквой ё. Английское слово
оставляют, когда это имя в коде, название продукта или аббревиатура (ADR,
API, SQL, OIDC). Один смысл во всех документах называют одним словом. У
утверждения есть источник, либо оно помечено как допущение. Персональные
данные заказчика в `docs/` не копируют.

## Что обновляют вместе с кодом

| Изменили | Обновляют ещё |
| --- | --- |
| Точку API | Её docblock (`@input`, `@output`) и список точек, если проект его ведёт |
| Столбец | `comment()` в миграции, блок `@property` модели, ER-схему, если она есть |
| Решение, которое потом придётся отменять отдельно | ADR |
| Переменную окружения | `.env.example` и README или реестр переменных |
| Поведение выпущенного пакета | `CHANGELOG.md` |

Второе дерево документов не заводят. Используют каталоги, которые в
репозитории уже есть.

## ADR

`DOC-02`. Каталог и имя файла — те, которые проект уже использует. Если их
ещё нет, берут `docs/adr/ADR-###-слаг.md`. Номер — следующий свободный.
Язык текста — `LANG-01`. Разделы по порядку:

1. Метаданные: идентификатор, автор, дата, статус.
2. Контекст: ситуация и требования, которым решение служит.
3. Решение: что выбрано.
4. Обоснование: какое требование или ограничение сделало этот выбор.
5. Альтернативы: выбранный вариант и хотя бы один отвергнутый, у каждого — цена.
6. Последствия: что стало проще, что стало труднее, что теперь запрещено.

Ссылаются по идентификатору (`ADR-004`), не по номеру строки. На ADR без
файла не ссылаются.

## Журнал изменений

Пакеты ведут [Keep a Changelog](https://keepachangelog.com/): разделы
`Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security` под
`[Unreleased]`, затем версия и дата, когда выпуск срезан. Версии кода
пакета — семантические. Версии этого пакета стандартов ещё и следуют
`STD-01`: новое требование — minor, смягчённое требование — major,
уточнение формулировки — patch.

## README продукта

В нём сказано, что это, как установить, как настроить и какие переменные
окружения оно читает. Команды можно скопировать. У переменной в таблице
есть имя, назначение и обязательность.

## Схемы

Mermaid — для структуры, последовательности и связей сущностей. Исходник
BPMN лежит рядом с markdown, если проект описывает процесс. У схемы есть
заголовок. Её обновляют в том же изменении, что и структуру, которую она
показывает.

## Этот пакет

`AGENTS.md` — файл, которому следуют модели. `docs/` объясняет те же
правила на примерах. `docs/ru/` — перевод для людей. Правило не выращивают
только в переводе. Сначала меняют `AGENTS.md` и английскую главу, затем
русскую главу в том же изменении.
