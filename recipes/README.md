# Recipes

Short procedures. The rules they apply are in `AGENTS.md`. When a recipe
and a rule disagree, the rule wins.

| Recipe | Use it when |
| --- | --- |
| [Adopt the standard](adopt-standard.md) | The project is about to require this package |
| [Audit](audit.md) | You need a report of which rules hold |
| [New endpoint](new-endpoint.md) | A forge-shaped `laravel-api` method |
| [Migration](migration.md) | A schema change, including live data |
| [Form and end-to-end scenario](form-with-e2e.md) | A screen gained a field or a button |
| [Characterization test](characterization-test.md) | Old behavior has no test and you are about to change it |
| [Move to a domain](move-to-domain.md) | One row of `docs/domain-map.md` |
